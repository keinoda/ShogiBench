# 複数テスト集計

ShogiBenchは棋譜を保存していないテストでも、Test行にW/D/LとPtnmlの5分類を
保持しています。「複数テスト集計」はこれらの集計値を直接使い、棋譜、合成PGN、
外部Ordo実行ファイルなしで複数AIの相対レーティングを計算します。

左側の「複数テスト集計」を開き、比較するテスト番号をカンマ、空白、または改行で
指定します。URLへ直接指定して同じ集計を再実行することもできます。

```text
/ratings/?tests=103,109,110
```

削除済みテストも番号を明示すれば利用できます。実行中テストも利用できますが、
集計後にW/D/LとPtnmlが変化する可能性があるため警告を表示します。SPSAとDATAGENは
通常の固定AI同士の対局ではないため対象外です。

## AIの同一性

AIは次の組で区別します。

```text
(network SHA, build commit SHA)
```

ブランチ名、表示名、ビルド引数、Threads、Hash、持時間、開始局面集はAIキーに
含めません。同じAIキーに異なる表示名やビルド引数がある場合は統合し、差を警告へ
表示します。

## 入力検証

各テストについて、計算前に次を検証します。

```text
games = wins + draws + losses
games = 2 × (LL + LD + DD + DW + WW)
2 × wins + draws = LD + 2 × DD + 3 × DW + 4 × WW
```

参加AIの対戦グラフが連結していない場合は、AI間の相対値を一意に決められないため
成分を表示して計算を中止します。同じAIキー同士の自己対局はレーティング情報を
持たないため除外します。

## 点推定

点推定にはW/D/Lを集計値のまま使用します。テストごとに次の対局数と得点を作ります。

```text
N = wins + draws + losses
S = wins + draws / 2
```

AI間の期待得点率をロジスティック関数で表し、全テストの集計対数尤度を同時に最大化
します。レーティング差202で期待得点率76%となるスケールを使用し、参加AIの平均を
0に固定します。1局ずつのデータへ展開しないため、28,282局を含む3テストでも
計算対象は3行の集計値です。

## Ptnmlによる区間推定

95%区間、優越確率、1位率にはPtnmlを使います。各テストの
`[LL, LD, DD, DW, WW]`を多項分布としてペア単位で10,000回再標本化し、各標本で
全体レーティングを再計算します。乱数seedは固定されるため、同じ入力から同じ結果を
再現できます。

## 条件差

次の条件差は計算を止めず、画面上で警告します。

- 開始局面集
- 制限時間
- Threads、Hash、Ponder
- NPSスケール
- 勝敗・引分判定
- Syzygy設定
- 同じAIキーに対応する表示名とビルド引数

条件差の補正やDB値の上書きは行いません。異なる条件を統合してよいかは結果を読む側が
判断します。

## 回帰確認用のテスト集合

旧32手開始局面集の比較にはテスト103・109・110を使用します。104・105では
ありません。

```text
/ratings/?tests=103,109,110
```

この集合の外部Ordoによる既知値は、参加AIの平均を0として次のとおりです。

```text
master:       +3.3
sojo_tsec7:   +1.0
V9.40 tuned:  -4.4
```

W/D/Lを直接解く実装は、それぞれ`+3.32`、`+1.04`、`-4.36`を再現します。

テスト119・120・122も3者の連結比較に利用できます。ただし、テスト120はDB上で
`40.0+0.40`、`Hash=256`、119・122は別条件です。現在の直接集計はDB値を変更せず、
条件差を警告したうえでそのまま計算します。
