Worker Keys

Worker Keys are dedicated credentials for connecting worker machines, such as rented vast.ai instances, to this server. On the worker, set OPENBENCH_USERNAME to your username and OPENBENCH_PASSWORD to a Worker Key token. Your account password never has to be copied onto a rented machine, and a leaked token can simply be deleted here. Tokens cannot log into this website.

Connect an Instance over SSH

Paste the instance's SSH address (e.g. vast.ai's ssh -p 12345 root@ssh4.vast.ai, or host:port) and the server will log in, install everything, and start the worker for you. For this to work, the instance must accept the following public key — add it once to your vast.ai account under Account › SSH Keys, and every new instance will include it automatically. For an already-running instance, append it to ~/.ssh/authorized_keys, or attach it from the vast.ai console if available.
