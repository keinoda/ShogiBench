ワーカーキー

ワーカーキーは、vast.ai などのワーカーマシンをこのサーバーに接続するための 専用の資格情報です。ワーカー側では OPENBENCH_USERNAME に ユーザー名を、OPENBENCH_PASSWORD にキーのトークンを設定します。 アカウントのパスワードを借りたマシンに置く必要はなく、トークンが漏れても このページで削除するだけで無効化できます。トークンでは Web にログインできません。

稼働中のマシン

「停止」を押すと、次の通信(30秒以内)で実行中の対局が中断され、 そのマシンには新しい仕事が配られなくなります。未完の対局は他の マシンへ配り直されるのでテストは壊れません。ワーカーが再起動して 新しいセッションになると停止要求は引き継がれないため、 長期間止める場合はワーカーキーの無効化もあわせて行ってください。

SSHでインスタンスを接続

インスタンスのSSHアドレス(vast.ai の ssh -p 12345 root@ssh4.vast.ai、AWS の ec2-user@203.0.113.7 や ubuntu@203.0.113.7)を 貼り付けると、サーバーが OPENBENCH_SSH_PRIVATE_KEY の 秘密鍵でログインし、依存関係のインストールからワーカーの起動まで 自動で行います。

{% if ssh_key_configured %}

サーバーのSSH鍵: {{ssh_key_fingerprint}}
普段使っている AWS と同じように、この鍵でSSHできる インスタンスなら追加の秘密鍵指定は不要です。

{% else %}

サーバーにSSH秘密鍵が設定されていません。 管理者が一度だけ次を実行してください (接続先へ既に入っている公開鍵に対応する、パスフレーズなしの鍵): 

fly secrets set OPENBENCH_SSH_PRIVATE_KEY="$(cat ~/.ssh/id_ed25519)"
{% endif %}

手動でワーカーを接続する

{% with keys.first as newest %}
