.tune キット

やねうら王のソースにTUNEマクロを注入して、探索パラメータをUSIオプション化する パッチ定義 (.tune) を管理します。SPSAチューニング作成でキットを選ぶと、 ワーカーがビルド前にソースへパッチを当てて TUNEビルド を作り、そのまま rshogi の spsa を回します。masterが進んでソースがずれたら、キットページの 「照合」→「数値ドリフトを自動追随」で更新します。

.tune の書式は Scripts/tune/ の tune.py と同じ (#set file / #context 名前 / 123@ マーカー / #add マーカー)。.params は省略すると .tune から自動生成されます (初期値=ソースの数値、レンジ=0〜2倍、step=可動域の1/20)。
